# Catalog screenshots

The [Flipper Application Catalog](https://catalog.flipperzero.one/) requires at least one screenshot taken with **qFlipper** (do not resize or reformat).

Before submitting the catalog PR, add PNG files here:

| File | Suggested content |
|------|-------------------|
| `01_main_menu.png` | Main menu (Configure / Write / Read) |
| `02_configure_tag.png` | Configure Tag screen with material and color |
| `03_write_tag.png` | Write Tag prompt or success |

Capture via qFlipper: connect Flipper → **Screenshot** → save as-is. Paths must match `catalog/manifest.yml`.
